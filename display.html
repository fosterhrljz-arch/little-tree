Little Tree

Open Little Tree with the local launcher

This app needs a local server. Opening an HTML file directly cannot load its application modules or share the portal's saved updates.

  1. Return to the little-tree project folder. If you are in dist, go up one folder.
  2. Double-click Start Little Tree.cmd.
  3. Keep the launcher window and portal tab open. The portal and TV page open in Microsoft Edge.

If the server is already running, open this page through the local server.

Use the same address and browser profile for all views. Files opened through file:// have separate browser storage.
